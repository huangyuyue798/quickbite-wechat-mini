# WeChat 外卖点餐小程序（wechat-waimai-mini）

一个基于**微信小程序** + **Node.js** 的外卖点餐系统，适合学习和个人项目实战。

### 项目简介
这是一个功能完整的外卖点餐微信小程序，支持用户浏览店铺、商品选择、购物车管理、下单、地址管理等核心流程。采用**前后端分离**架构，前端使用原生微信小程序开发，后端使用 Node.js + Express/Koa 实现。

**技术栈**：
- 前端：微信小程序（WXML + WXSS + JavaScript）
- 后端：Node.js + Express / Koa + MySQL
- 数据库：MySQL
- UI 组件：Vant Weapp（可选）
- 部署：腾讯云 / 阿里云 / Docker

### 主要功能
- ✅ 用户微信授权登录
- ✅ 店铺列表 + 搜索 + 分类
- ✅ 商品详情 + 购物车
- ✅ 地址管理 + 定位
- ✅ 下单 + 订单状态流转
- ✅ 商家端简单接单管理（规划中）

### 项目目的
